# Parity Decision Log

Each row records a behavior on which the port and the VB6 compiler can differ: its decision, the VB6 source
lines it cites and the tests that hold the port to it. A `Match VB6` row records a decision to keep VB6's
behavior, and its decision cell says what both compilers do. An `Intentional` row is a deliberate exception to
the [parity rules](../CONVENTIONS.md#parity), and its section on
[the differences pages](DIFFERENCES-FROM-VB6.md) says what VB6 and the port each do.

**Rules**

1. A row cites the VB6 source lines the port follows or departs from, where VB6 has code to cite.
2. A decision is `Match VB6` or `Intentional`, and an intentional row links its section of the differences
   pages; no decision is implicit.
3. A row lands with its code and names the test that enforces it.

**VB6 source references** name a file by its name alone: `Module1.bas`, `Mod_ScriptDat.bas` and
`Principale.frm` are in `Original Compiler/Progetti/NG_Scripter/`, and `MioModulo.bas` is
`Original Compiler/MioModulo.bas`.
The line numbers are those of the maintainer's instrumented copy, and
[CONTRIBUTING.md](../CONTRIBUTING.md#vb6-citations) lists how a pristine download maps to them.
